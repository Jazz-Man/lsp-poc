# Remove CLI Vestige — stdio-only Entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Delete the socket-era CLI scaffolding (`src/cli/`, clap, launcher args) so `main.rs` calls `serve()` directly, and correct the six doc statements that described the old shape (spec `docs/superpowers/specs/2026-09-13-rm-cli-design.md`).

**Architecture:** Four tasks: (1) the whole server crate in one atomic edit — delete `cli/`, rewire `main.rs`, drop the clap dependency, de-cli `arch-lint.toml` (they only compile/validate together); (2) the extension launcher drops its dead arguments; (3) six documentation corrections; (4) full verification battery plus the deny/dupes ripple report.

**Tech Stack:** Rust edition 2024, `async-language-server` v0.10.0 (`serve(server)` over stdio), `arch-lint` dev-dep validating `arch-lint.toml`, Makefile battery (`fmt`, `clippy`, `doc`, `test`, `dylint`).

## Global Constraints

- Git is read-only for every agent: NO `git add`, `git commit`, `git rm`, or any other git-write command. The owner commits. (This plan has no commit steps by design.)
- Surgical: zero changed lines outside the spots specified below. Do not reformat, re-wrap, or "improve" adjacent text.
- Every `old_string` below must match the file exactly — if it does not, STOP and report BLOCKED instead of improvising.
- Zero new dependencies; one dependency removed (clap).
- Never print to stdout in server code (it is the LSP transport) — not touched by this plan, but no step may introduce it.
- Subagents verify with the commands given; the controller verifies by diff (`git diff` redirected to a file — never pasted into chat).

//! Proof-of-concept Markdown language server over the LSP protocol, built on
//! the owner's `async-language-server` fork and served over stdio.

mod hovers;
mod server;
mod tracing;

use anyhow::Context;
use async_language_server::server::serve;
use self::tracing::setup_tracing;
use crate::server::PocLanguageServer;

#[tokio::main(flavor = "current_thread")]
async fn main() -> anyhow::Result<()> {
    setup_tracing();

    serve(PocLanguageServer::new())
        .await
        .context("encountered fatal error - language server shutting down")
}
