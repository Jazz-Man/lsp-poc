# Cycle 4 — Rename Capability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve `textDocument/rename` + `textDocument/prepareRename`: a heading renames its text and every inbound link/wikilink fragment across candidate documents; reference↔definition and footnote-ref↔footnote-def rename in pairs; a link/wikilink renames its fragment (or, for a fragment-less wikilink, its target text); web and fragment-less file destinations answer `None` — per `docs/superpowers/specs/2026-09-15-md-rename-design.md`.

**Architecture:** The model gains precision sub-ranges collected at parse time from already-typed grammar children (`content_range`, `fragment_range`, `label_range`, `id_range`) — `api-parse-dont-validate`: ranges validated at construction, no byte-scanning at rename time. New `src/renames/` computes `prepare_at` (sub-range under cursor) and `at_position` (an edit map sorted by descending start position per file, returned as `WorkspaceEdit::changes`). Server wires the canonical pair (`rename_provider: OneOf::Right(RenameOptions { prepare_provider: Some(true) })` + both methods) over the same resolver/`resolve_from`/snapshot seams as references.

**Tech Stack:** unchanged — Rust 2024 stable, `async-language-server` v0.10.0, `tree-sitter-md` 0.5.3, `cargo nextest`, Makefile battery. **Zero new dependencies.**

```rust
fn collect_definition(definition: Node, text: &str, index: &mut MdIndex) {
    let mut cursor = definition.walk();
    let Some(label_node) = definition
        .children(&mut cursor)
        .find(|child| child.kind() == "link_label")
    else {
        return;
    };
    let Some(raw) = bracketed_text(label_node, text) else {

    };
```

```rust
/// The bytes INSIDE a `[label]` node — brackets stripped — as a
/// document-absolute range (the rename replaces bare label text).
/// Labels are single-line (the `link_label` grammar node).
fn inner_range(label_node: &Node, text: &str) -> Range {
    let raw = label_node
        .utf8_text(text.as_bytes())
        .expect("label node text is valid utf-8");
    let leading = raw.len() - raw.trim_start_matches('[').len();
    let trailing = raw.len() - raw.trim_end_matches(']').len();
    let start = label_node.start_byte() + leading;
    let inner_len = label_node.end_byte() - trailing - start;
    let start_col = label_node.start_position().column + leading;
    Range {
        start_byte: start,
        end_byte: start + inner_len,
        start_point: Point {
            row: label_node.start_position().row,
            column: start_col,
        },
        end_point: Point {
            row: label_node.start_position().row,
            column: start_col + inner_len,
        },
    }
}
```

```rust
/// The renameable sub-range under `position`, or `None` when nothing
/// renameable is under it. The sub-range is what `textDocument/rename`
/// replaces; the server slices the document text at it for the
/// prepare-rename placeholder.
pub fn prepare_at(
    index: &links::MdIndex,
    position: LspPosition,
) -> Option<async_language_server::tree_sitter::Range> {
    let at = |range: async_language_server::tree_sitter::Range| {
        async_language_server::tree_sitter_utils::ts_range_contains_lsp_position(
            range,
            position,
        )
    };
    match item_at(index, position)? {
        CursorItem::Heading(heading) => Some(heading.content_range),
        CursorItem::Link(link) => link.fragment_range,
        CursorItem::Wikilink(wikilink) => wikilink.fragment_range,
        CursorItem::Reference(reference) => Some(reference.range),
        CursorItem::Definition(definition) => Some(definition.label_range),
        CursorItem::FootnoteReference(footnote) => Some(footnote.id_range),
        CursorItem::FootnoteDefinition(definition) => Some(definition.id_range),
    }
}

/// Computes the rename edit map for the item under `position`, or `None`
/// when nothing renameable is under it or the new name is empty. Edits
/// within each file are sorted by descending start position.
pub fn at_position(
    index: &links::MdIndex,
    self_url: &Url,
    position: LspPosition,
    new_name: &str,
    documents: &[DocumentSnapshot],
    resolve: &dyn Fn(&Target) -> Option<Resolved>,
    resolve_from: &dyn Fn(&Url, &Target) -> Option<Resolved>,
) -> Option<WorkspaceEdit> {
    if new_name.is_empty() {
        return None;
    }
    let mut edits: HashMap<Url, Vec<TextEdit>> = HashMap::new();
    match item_at(index, position)? {
        CursorItem::Heading(heading) => {
            push_edit(&mut edits, self_url, heading.content_range, new_name);
            let slug = &heading.slug;
            for document in documents {
                for link in document.index.links() {
                    let Some(target) = parse_destination(&link.destination) else {
                        continue;
                    };
                    if lands_on(slug, self_url, &document.url, &target, resolve_from) {
                        let Some(fragment_range) = link.fragment_range else {
                            continue;
                        };
                        push_edit(
                            &mut edits,
                            &document.url,
                            fragment_range,
                            &slugify(new_name),
                        );
                    }
                }
                for wikilink in document.index.wikilinks() {
                    let Some(target) = parse_wiki_target(&wikilink.target) else {
                        continue;
                    };
                    if lands_on(slug, self_url, &document.url, &target, resolve_from) {
                        let Some(fragment_range) = wikilink.fragment_range else {
                            continue;
                        };
                        push_edit(
                            &mut edits,
                            &document.url,
                            fragment_range,
                            &slugify(new_name),
                        );
                    }
                }
            }
        }
        CursorItem::Reference(reference) => {
            push_edit(&mut edits, self_url, reference.range, new_name);
            let definition = index
                .definitions()
                .iter()
                .find(|definition| definition.label == reference.label)?;
            push_edit(&mut edits, self_url, definition.label_range, new_name);
        }
        CursorItem::Definition(definition) => {
            push_edit(&mut edits, self_url, definition.label_range, new_name);
            for reference in index.references() {
                if reference.label == definition.label {
                    push_edit(&mut edits, self_url, reference.range, new_name);
                }
            }
        }
        CursorItem::FootnoteReference(footnote) => {
            push_edit(&mut edits, self_url, footnote.id_range, new_name);
            let definition = index
                .footnote_definitions()
                .iter()
                .find(|definition| definition.id == footnote.id)?;
            push_edit(&mut edits, self_url, definition.id_range, new_name);
        }
        CursorItem::FootnoteDefinition(definition) => {
            push_edit(&mut edits, self_url, definition.id_range, new_name);
            for footnote in index.footnote_references() {
                if footnote.id == definition.id {
                    push_edit(&mut edits, self_url, footnote.id_range, new_name);
                }
            }
        }
        CursorItem::Wikilink(wikilink) => {
            let target = parse_wiki_target(&wikilink.target)?;
            match (wikilink.fragment_range, &target) {
                (Some(fragment_range), Target::Wiki { fragment: Some(_), .. }) => {
                    push_edit(
                        &mut edits,
                        self_url,
                        fragment_range,
                        &slugify(new_name_placeholder(new_name)),
                    );
                }
                (None, Target::Wiki { .. }) => {
                    push_edit(&mut edits, self_url, wikilink.range, new_name);
                }
                _ => return None,
            }
        }
        // Fragment-less file links answer None: file renames are
        // `workspace/willRename`, out of scope.
        CursorItem::Link(_) => return None,
    }
    for edits_in_file in edits.values_mut() {
        edits_in_file.sort_unstable_by(|left, right| {
            right.range.start.line.cmp(&left.range.start.line).then(
                right
                    .range
                    .start
                    .character
                    .cmp(&left.range.start.character),
            )
        });
    }
    Some(WorkspaceEdit {
        changes: Some(edits),
        ..WorkspaceEdit::default()
    })
}

/// Registers one edit for `url`, converting the model range to LSP
/// coordinates.
fn push_edit(
    edits: &mut HashMap<Url, Vec<TextEdit>>,
    url: &Url,
    range: async_language_server::tree_sitter::Range,
    new_text: &str,
) {
    edits.entry(url.clone()).or_default().push(TextEdit {
        range: async_language_server::tree_sitter_utils::ts_range_to_lsp_range(range),
        new_text: new_text.to_owned(),
    });
}

/// `true` when `target`, resolved in the candidate document's context,
/// lands on the heading named `slug` in the requesting document.
fn lands_on(
    slug: &str,
    self_url: &Url,
    candidate_url: &Url,
    target: &Target,
    resolve_from: &dyn Fn(&Url, &Target) -> Option<Resolved>,
) -> bool {
    match target {
        Target::Fragment(fragment) => {
            candidate_url == self_url && slugify(fragment) == slug
        }
        Target::Doc { fragment, .. } | Target::Wiki { fragment, .. } => {
            let Some(Resolved::Found { url, .. }) = resolve_from(candidate_url, target) else {
                return false;
            };
            url == *self_url
                && fragment
                    .as_deref()
                    .is_some_and(|fragment| slugify(fragment) == slug)
        }
    }
}

fn slugify_placeholder(new_name: &str) -> String {
    slugify(new_name)
}
```

```rust
    /// Answers one `textDocument/prepareRename` request: the renameable
    /// sub-range under the position, with the old text as the placeholder.
    fn rename_prepare_at(
        &self,
        state: &ServerState,
        params: &TextDocumentPositionParams,
    ) -> ServerResult<Option<PrepareRenameResponse>> {
        let url = &params.text_document.uri;
        let position = params.position;

        let Some(doc) = state.document(url) else {
            return Ok(None);
        };
        let text = doc.text_contents();
        let Some(index) = self.parse(&text) else {
            tracing::debug!("markdown parse produced no tree; no rename for {url}");
            return Ok(None);
        };
        let Some(range) = renames::prepare_at(&index, position) else {
            return Ok(None);
        };
        let Some(placeholder) = text.get(range.start_byte..range.end_byte) else {
            tracing::warn!("rename range is out of the document bounds; no rename for {url}");
            return Ok(None);
        };
        Ok(Some(PrepareRenameResponse::RangeWithPlaceholder {
            range: ts_range_to_lsp_range(range),
            placeholder: placeholder.to_owned(),
        }))
    }

    /// Answers one `textDocument/rename` request with the per-file edit
    /// map. Absence is a normal `None`: no document, no parse, nothing
    /// renameable under the position, or an empty new name.
    fn rename_at(
        &self,
        state: &ServerState,
        params: &RenameParams,
    ) -> ServerResult<Option<WorkspaceEdit>> {
        let url = &params.text_document_position.text_document.uri;
        let position = params.text_document_position.position;

        let Some(doc) = state.document(url) else {
            return Ok(None);
        };
        let text = doc.text_contents();
        let Some(index) = self.parse(&text) else {
            tracing::debug!("markdown parse produced no tree; no rename for {url}");
            return Ok(None);
        };
        let documents = self.document_snapshots(state);
        let resolve = self.resolver(state, url);
        let files = &self.files;
        let resolve_from = |candidate_url: &Url, target: &Target| {
            let open = |open_url: &Url| {
                state
                    .document(open_url)
                    .and_then(|open_doc| self.parse(&open_doc.text_contents()))
            };
            files.resolve(&open, candidate_url, target)
        };
        Ok(renames::at_position(
            &index,
            url,
            position,
            &params.new_name,
            &documents,
            &resolve,
            &resolve_from,
        ))
    }
```
