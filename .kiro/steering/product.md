# Product Overview

A Rust-based Language Server Protocol (LSP) implementation for PHP, designed to provide intelligent code assistance, navigation, and analysis for PHP developers. Includes specialized support for WordPress hooks and integrates with the Zed editor.

## Core Capabilities

- **PHP Language Analysis**: Parse and analyze PHP code with Tree-sitter
- **LSP Protocol Implementation**: Full support for LSP features (completions, diagnostics, goto definition, etc.)
- **WordPress Hooks Support**: Specialized support for WordPress development
- **Zed Editor Integration**: Dedicated extension for the Zed code editor

## Target Use Cases

- PHP development with intelligent code completion
- WordPress theme/plugin development with hook detection
- Code navigation and refactoring in PHP projects
- Integration with modern code editors supporting LSP

## Value Proposition

A specialized, high-performance PHP LSP server implemented in Rust for memory safety and performance, with particular emphasis on WordPress development workflows. Designed for seamless integration with the Zed editor while following LSP standards for broader compatibility.
